# safwanx.github.io

Personal website for **Safwan Islam Nabeel**, hosted with GitHub Pages.

## Files

- `index.html` - page content and structure
- `styles.css` - all styling and responsive layout
- `script.js` - mobile navigation and small UI behavior
- `favicon.svg` - browser icon
- `.nojekyll` - tells GitHub Pages to serve the site as plain static files
- `assets/Safwan_CV.pdf` - downloadable CV
- `assets/safwan-portrait.jpg` - optimized website portrait
- `assets/pic.JPG` - original full-resolution portrait
- `PRODUCT.md` - strategic product and content direction

## Deploy

Put all files in the root of the `safwanx.github.io` repository and commit them to `main`.

GitHub Pages will serve the site at:

`https://safwanx.github.io`

## Included content

The page includes Safwan's publication and code links, selected research and
engineering work, professional experience, education, honors, CV, portrait,
and public contact profiles.
